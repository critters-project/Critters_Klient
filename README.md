# Critters

Stworek, który żyje na twoim pulpicie Windows. Ma własny charakter i zachowuje się jak prawdziwe zwierzę.
Przez klienta walk wchodzi do pokoju: z dzikim stworkiem z serwera (możesz go złapać) albo ze stworkiem innego gracza.

**Critters jest darmowy (freeware).** To nie jest projekt open source: w tym repozytorium jest tylko instalator
i licencja, bez kodu źródłowego.

## Pobieranie

Zakładka **Releases** (po prawej) → najnowsza wersja → **Critters_Setup.exe**.

Wymagania: Windows 10 albo 11, 64-bit, połączenie z internetem przy dodawaniu stworka.

## Jak zacząć

1. Załóż konto na **https://critters-game.duckdns.org** i potwierdź je linkiem z maila.
2. Token stworka dostajesz od administratora (albo kod, który wpisujesz na stronie w **Koncie**).
3. Zaloguj się w **sejfie**: **https://sejf.critters-game.duckdns.org** i pobierz paczkę **.crit** swojego tokenu.
4. Uruchom **Critters_Setup.exe**: zaakceptuj licencję, zainstaluj grę, wskaż paczkę .crit i wpisz token.

Instalator nie zawiera żadnych stworków. Wygląd, głos i zasady stworka są tylko w paczce z sejfu,
która działa raz i tylko z twoim tokenem.

Kolejnego stworka dodajesz: menu Start → Critters → **Dodaj stworka**.
Odinstalowanie: menu Start → Critters → **Odinstaluj Critters** (albo Ustawienia → Aplikacje).

### Windows ostrzega przed instalatorem?

Instalator nie ma płatnego podpisu cyfrowego, więc SmartScreen może pokazać „System Windows ochronił ten komputer”.
Kliknij **Więcej informacji → Uruchom mimo to**. Pobieraj instalator tylko z tej strony.
